# libs/

Сюда нужно вручную положить бинарники сторонних плагинов, от которых зависят
VIP-модули (мы не распространяем и не собираем их из исходников):

- `VipCoreApi.dll` — API плагина VIP-Core / VIP-CS2, который вы используете.

Без этого файла VIP-модули (`CS2-VIP-LR-ExperienceMultiplier`,
`CS2_VIP_LR_CustomFakeRank`) не соберутся — сборочный workflow это учитывает
и просто пропускает их, не роняя остальную сборку (см. .github/workflows/build.yml).
